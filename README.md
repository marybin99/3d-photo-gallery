# 3D 온라인 사진전 

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서:

```bash
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:5173/`을 여세요.

## 포함된 기능

캐릭터의 색·체형 변경과 외부 모델 교체 방법: [캐릭터 변경 안내](docs/CHARACTER_GUIDE.md)

- 중앙 로비와 출입문으로 연결된 독립 A·B·C 전시실 (각 16 × 16), 3인칭 캐릭터
- 접속 시 입장 화면 없이 바로 로비에서 시작, W/S 전후 이동, A/D 좌우 이동 (방향키도 동일)
- PC: 마우스 왼쪽 버튼을 누른 채 드래그하여 좌우·상하 시야 회전, 바라보는 방향을 기준으로 이동
- 이동 방향으로 몸을 돌리는 캐릭터: 왼쪽·오른쪽·뒤·대각선 모두 그쪽을 바라보고 앞으로 걷기
- 팔·다리·무릎 보행, 몸통 흔들림과 대기 호흡, 부드러운 출발·정지
- 원형 캐릭터 충돌, 벽을 따른 미끄러짐, 책상·출입문 기둥 충돌, 얇은 벽 관통 방지
- 모바일: 우측 하단 조이스틱으로 자유 방향 이동, 밀어낸 거리에 따른 속도 조절과 중앙 데드존
- 모바일: 다른 손가락의 화면 드래그로 시야 회전, 손을 떼거나 터치가 취소되면 이동 입력 해제
- 모바일 가로 화면: 조이스틱·상단 정보·미니맵 축소, 안전 영역 여백, 작품 상세 2열 배치
- 화면 회전·크기 변경 시 조이스틱 입력 초기화
- 액자 클릭 시 작품 확대
- 우측 위 실시간 위치·방향 미니맵, 지도 숨기기, 입구로 이동
- 접속 시 바로 로비 표시, 중앙의 큰 조작 안내 팝업을 확인·X로 닫기
- 조작 안내 다시 열기: 좌측 하단 버튼 위 작은 안내, 방향키 모양과 각 키 아래 W/A/S/D 표기
- 모바일 터치 조이스틱
- 로비 책상 위 펼쳐진 책 클릭 또는 가까이서 E 키/책 열기 버튼으로 방명록 열기
- 방명록 화면 및 글 남기기
- 기본 12개의 **사진이 아닌 데모 SVG 풍경 그림** 포함 — 사용자 사진으로 교체 필요

## 공간 구성

```text
                ┌────────────┐
                │  B 전시실  │
                └─────┬──────┘
┌────────────┬────────┴───────┬────────────┐
│  A 전시실  │      로비      │  C 전시실  │
│  작품 4점  │  방명록 · 입장 │  작품 4점  │
└────────────┴────────────────┴────────────┘
```

로비에서 세 전시실을 자유롭게 오갈 수 있습니다. `로비로 이동` 버튼으로 시작 위치에 복귀합니다. 공간·벽·이동 판정·미니맵 좌표는 `src/layout.ts`를 기준으로 사용합니다.

Node.js 22.6+에서 `npm test`로 출입문 통과, 벽·책상·문기둥 충돌, 벽 관통 방지, 이동 방향 회전과 마우스 입력을 검증할 수 있습니다.

## 방명록 저장소 상태

Supabase를 연결하지 않은 기본 상태에서는 **방명록이 이 브라우저의 localStorage에만 저장됩니다.** 다른 방문자는 볼 수 없습니다.

`.env.example`을 `.env`로 복사한 후 Supabase URL 및 anon key를 추가하면 공개 방명록 조회 코드가 활성화됩니다.
`supabase/schema.sql`을 SQL Editor에서 적용하면 공개 글 조회 정책이 설정됩니다. **쓰기 정책은 열어 두지 않았습니다.** 실제 공개 방명록 저장은 서버 측 CAPTCHA/Turnstile 확인과 rate limit이 있는 Edge Function을 추가하고 프런트엔드의 `Guestbook.submit`을 해당 함수로 연결해야 합니다. 현재 Supabase 연결만으로는 방문자 글 등록이 성공하지 않습니다.
