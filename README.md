# 3D 온라인 사진전 

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서:

```bash
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:5173/`을 여세요.

## 포함된 기능

캐릭터의 색·체형 변경과 외부 모델 교체 방법: [캐릭터 변경 안내](docs/CHARACTER_GUIDE.md)

- 중앙 로비와 출입문으로 연결된 독립 A·B·C 전시실 (각 16 × 16), 3인칭 캐릭터
- 접속 시 입장 화면 없이 바로 로비에서 시작, W/S 전후 이동, A/D 좌우 이동 (방향키도 동일)
- PC: 마우스 왼쪽 버튼을 누른 채 드래그하여 좌우·상하 시야 회전, 바라보는 방향을 기준으로 이동
- 이동 방향으로 몸을 돌리는 캐릭터: 왼쪽·오른쪽·뒤·대각선 모두 그쪽을 바라보고 앞으로 걷기
- 팔·다리·무릎 보행, 몸통 흔들림과 대기 호흡, 부드러운 출발·정지
- 원형 캐릭터 충돌, 벽을 따른 미끄러짐, 책상·출입문 기둥 충돌, 얇은 벽 관통 방지
- 모바일: 우측 하단 조이스틱으로 자유 방향 이동, 밀어낸 거리에 따른 속도 조절과 중앙 데드존
- 모바일: 다른 손가락의 화면 드래그로 시야 회전, 손을 떼거나 터치가 취소되면 이동 입력 해제
- 모바일 가로 화면: 조이스틱·상단 정보·미니맵 축소, 안전 영역 여백, 작품 상세 2열 배치
- 화면 회전·크기 변경 시 조이스틱 입력 초기화
- 각 전시실의 정면·왼쪽·오른쪽 벽에 4점씩, 전시실당 12점 · 전체 36개 전시 위치
- 좌우 구분은 로비에서 해당 전시실에 들어서는 방향 기준
- 추가 전시 위치는 기존 데모 이미지를 재사용하며 실제 사진으로 교체 가능
- 액자 클릭 시 작품 확대
- 우측 위 실시간 위치·방향 미니맵, 지도 숨기기, 입구로 이동
- 접속 시 바로 로비 표시, 중앙의 큰 조작 안내 팝업을 확인·X로 닫기
- 조작 안내 다시 열기: 좌측 하단 버튼 위 작은 안내, 방향키 모양과 각 키 아래 W/A/S/D 표기
- 모바일 터치 조이스틱
- 로비 책상 위 펼쳐진 책 클릭 또는 가까이서 E 키/책 열기 버튼으로 방명록 열기
- 방명록 화면 및 글 남기기
- 기본 12개의 **사진이 아닌 데모 SVG 풍경 그림** 포함 — 사용자 사진으로 교체 필요

## 공간 구성

```text
                ┌────────────┐
                │  B 전시실  │
                └─────┬──────┘
┌────────────┬────────┴───────┬────────────┐
│  A 전시실  │      로비      │  C 전시실  │
│  작품 12점 │  방명록 · 입장 │  작품 12점 │
└────────────┴────────────────┴────────────┘
```

로비에서 세 전시실을 자유롭게 오갈 수 있습니다. `로비로 이동` 버튼으로 시작 위치에 복귀합니다. 공간·벽·이동 판정·미니맵 좌표는 `src/layout.ts`를 기준으로 사용합니다.

Node.js 22.6+에서 `npm test`로 출입문 통과, 벽·책상·문기둥 충돌, 벽 관통 방지, 이동 방향 회전과 마우스 입력을 검증할 수 있습니다.

## 운영자 로그인과 작품 관리

관리자 주소는 **사이트 주소 + `/#/admin`**입니다. 예: `http://localhost:5174/#/admin`.

- Supabase Auth 이메일·비밀번호 로그인, DB에서 운영자 권한 확인
- 사진 업로드·미리보기·교체, 제목·설명 편집, 36개 액자 중 전시 위치 선택
- 공개·비공개 전환, 작품 삭제와 사용하지 않는 사진 정리
- 전시실 이름 수정: 입구·미니맵·현재 위치·작품 관리에 반영
- 등록되지 않았거나 비공개인 위치는 빈 액자 표시
- 관리자에서 전시관으로 돌아갈 때 해시 없는 `/` 주소 사용
- 비공개 Storage와 DB RLS 정책, 중복 위치와 동시 수정 충돌 검사
- Supabase 연결 시 전시관은 DB의 공개 작품만 표시; 미설정 시 기존 데모 표시

**처음부터 연결하는 절차:** [관리자·Supabase 설정 안내](docs/ADMIN_SETUP.md)

## 방명록 저장소 상태

Supabase 미설정 시 방명록은 현재 브라우저의 localStorage에만 저장됩니다. 다른 방문자와 공유되지 않습니다.

Supabase 연결 후 추가 SQL과 `guestbook-submit` Edge Function을 적용하면 방문자가 로그인 없이 별명과 글을 남길 수 있습니다. 연속 등록 제한과 중복 요청 처리를 포함하며, Cloudflare Turnstile은 선택적으로 연결할 수 있습니다. **[공개 방명록 설정 안내](docs/GUESTBOOK_SETUP.md)** 순서대로 SQL·함수·허용 주소를 적용해야 실제 등록이 동작합니다.

## 참고

- 데모의 전시 위치·샘플 이미지는 `src/data.ts`에서 관리합니다. Supabase 연결 후 실제 작품 정보는 관리자 화면에서 수정합니다.
- 현재 캐릭터는 3D 도형으로 만든 시제품입니다.
