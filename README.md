# 3D 온라인 사진전 

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서:

```bash
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:5173/`을 여세요.

## 포함된 기능

- 3D 전시 공간, 3인칭 캐릭터, WASD/방향키 이동, 벽 경계 제한
- 액자 클릭 시 작품 확대, 입장 화면
- 우측 위 실시간 위치·방향 미니맵, 지도 숨기기, 입구로 이동
- 모바일 터치 조작 버튼
- 방명록 화면 및 글 남기기
- 기본 12개의 **사진이 아닌 데모 SVG 풍경 그림** 포함 — 사용자 사진으로 교체 필요

## 방명록 저장소 상태

Supabase를 연결하지 않은 기본 상태에서는 **방명록이 이 브라우저의 localStorage에만 저장됩니다.** 다른 방문자는 볼 수 없습니다.

`.env.example`을 `.env`로 복사한 후 Supabase URL 및 anon key를 추가하면 공개 방명록 조회 코드가 활성화됩니다.
`supabase/schema.sql`을 SQL Editor에서 적용하면 공개 글 조회 정책이 설정됩니다. **쓰기 정책은 열어 두지 않았습니다.** 실제 공개 방명록 저장은 서버 측 CAPTCHA/Turnstile 확인과 rate limit이 있는 Edge Function을 추가하고 프런트엔드의 `Guestbook.submit`을 해당 함수로 연결해야 합니다. 현재 Supabase 연결만으로는 방문자 글 등록이 성공하지 않습니다.
