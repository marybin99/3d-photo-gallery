# 프로젝트 인수 및 구현 현황

확인일: 2026-11-13

## 기준과 미확인 사항

현재 저장소의 README와 소스코드를 기준으로 정리했습니다. 이전 ChatGPT 공유 대화는 접근에 실패했으므로, 그 대화의 요구사항과 결정 사항을 확인한 문서는 아닙니다. 대화 내용을 받은 뒤 아래 개발 순서와 UI 방향을 대조해야 합니다.

## 현재 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.tsx` | 입장 화면, 전시 UI, 미니맵, 작품 상세, 방명록, 모바일 입력 |
| `src/Gallery.tsx` | 전시장 지오메트리, 액자, 캐릭터, 이동 경계, 추적 카메라 |
| `src/data.ts` | 12개 데모 작품의 정보와 3D 배치 |
| `src/supabase.ts` | 선택적 Supabase 연결과 로컬 방명록 저장 |
| `src/styles.css` | 베이지 계열 UI와 모바일 레이아웃 |
| `public/artworks/` | 데모 SVG 12개; 실제 사진으로 교체 필요 |
| `supabase/schema.sql` | 방명록 테이블과 공개 글 조회 RLS 정책 |

기술 스택은 React 19, TypeScript, Vite 7, Three.js, React Three Fiber, Drei, Supabase입니다. 별도 서버, 라우터, 관리자 화면은 없습니다.

## 구현된 기능

- THE QUIET ROOM 입장 화면과 3인칭 전시장 관람
- WASD/방향키 이동·회전, 사각형 경계 제한, 추적 카메라
- 작품 클릭 상세 보기, 미니맵 위치·방향 표시, 지도 숨김
- 입구 위치 복귀, 조작 안내, 나가기, 모바일 조작 버튼
- 방명록 로컬 저장; Supabase 설정 시 공개 글 조회

전시장은 하나의 직사각형 방이며 작품을 A/B/C 구역으로 나눕니다. 입장 화면의 `3 ROOMS` 문구와 실제 방 개수는 일치하지 않습니다. 이전 설계가 3개 방인지 3개 구역인지 확인해야 합니다.

## 이번 수정

- Vite 환경변수 타입 선언과 미사용 변수 정리로 TypeScript 빌드 오류 4건 해결
- 방명록/작품 상세가 열린 동안 키보드·모바일 이동 중지
- 입력창 및 버튼의 키 입력과 브라우저 단축키를 이동 처리에서 제외
- 창 포커스 이탈·탭 전환 시 이동 입력 초기화
- 키보드와 모바일 동시 입력 시 이동 속도 제한
- Escape로 팝업 닫기, 작품 상세 대화상자에 접근성 이름 추가

## 남아 있는 작업

README에 기록된 다음 단계이며, 이전 공유 대화에서 최종 확정된 사항인지는 확인이 필요합니다.

1. 운영자 인증·권한, 작품 DB와 Storage, 작품 관리 화면
2. 실제 사진 업로드 및 작품 메타데이터·배치 로딩
3. 서버 검증과 요청 제한을 갖춘 방명록 등록, 숨김·삭제
4. 마우스 카메라 회전, 캐릭터 애니메이션, 충돌 처리 개선
5. 모바일 실기기 성능 점검, 배포와 도메인 연결

Supabase 직접 INSERT 정책은 없습니다. 프런트엔드는 아직 직접 INSERT를 시도하므로 연결만으로 공개 방명록 쓰기가 완성되지 않습니다. 데모 방명록은 브라우저별로 저장되며 방문자끼리 공유되지 않습니다.

팝업 포커스 이동·가두기·복귀, 3D 리소스 로딩/오류 UI, 실제 사진 종횡비 보존도 추가 점검이 필요합니다.

## 검증

- `npm run build`: 통과
- 번들 크기 경고: JS 약 1.24 MB, gzip 약 358 KB; 코드 분할 검토 필요
- 브라우저 자동 검증: 실행 환경에서 로컬 디버깅 포트 접근이 `EPERM`으로 차단되어 미완료
- 외부 서비스 생성, DB 변경, 배포는 수행하지 않음

이전 대화를 전달할 때는 필수 기능, 확정 UI/전시장 구조, 운영자 흐름, 기술 제약, 마지막 작업 지점을 포함하면 설계를 이어갈 수 있습니다.
